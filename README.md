# sduu.dev

My personal portfolio, built as a static site with Astro and Tailwind CSS.

## Setup

Use Node.js 22.12 or newer, then install the dependencies:

```bash
npm install
```

## Development

```bash
npm run dev
```

Then open [http://localhost:4321](http://localhost:4321) to see the site.

## Production build

```bash
npm run build
```

The static site is written to `dist/` and can be deployed directly to Cloudflare.
